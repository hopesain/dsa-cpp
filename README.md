# Data Structures and Algorithms in C++
Data Structures and Algorithms in C++: Practice repository for my postgraduate studies in Data Science.

## Compilation and Running the code
- For my sake, I am using g++ GNU compiler. Assuming you are in the primer directory and want to run the hello.cpp file, run the following command regardless of your operating system:
`g++ hello.cpp -o hello`
- I am using windows, so to run the executable, just type `./hello.exe` in the terminal. For other operating systems, kindly do your research.
