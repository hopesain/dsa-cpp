# Data Structures and Algorithms in C++
A practice repository for my postgraduate studies in Data Science.

## Coding Approach
This is an academic repository, therefore, all solutions and implementations are **human-written**. In other words, I have adopted **zero-token architecture**.
However, I have to admit that all problem sets in the `basics.cpp` files across the different directories are generated by **Kimi AI**. The problems are generated for me to solve; the solutions are mine.

## Compilation and Running the Code
For my own sanity, I am using the **GNU C++ compiler (`g++`)**.
Assuming you are in the `primer` directory and want to compile `basics.cpp`, run:

```bash
g++ basics.cpp -o basics
```

I am using Windows, so to run the executable:
```bash
./basics.exe
```
For other operating systems, kindly do your own research.
